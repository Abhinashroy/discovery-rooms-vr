# Original footstep recording

`walk sound.mp3` is the supplied four-thud source. `scripts/extract-footstep.py` reproduces the single-thud runtime clip in `public/audio/footstep.wav`.

Opening and celebration recordings live only in `public/audio/start.mp3` and `public/audio/Hooray.m4a`; byte-identical source duplicates were removed during repository cleanup. Asset scripts are optional; the checked-in runtime audio is ready to use.
